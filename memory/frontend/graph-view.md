# Graph and tree views: one layout per object, elkjs in its own worker, drawn by sigma

Decided 2026-10-26 (FE-14); sigma drawing added the same day.

**Decision:**

- A graph or tree is laid out once per object, over the union of every edge that object holds at any step (`graphUnion` in the engine worker), so nodes never move while the program reads its edges or fills `par[]`. The union is undirected when every edge in it has its reverse; the checkbox overrides that. Layers are BFS levels from the lowest node of each component, fed to elkjs as partitions. Above 200 nodes the current step's 2-hop neighbourhood of the current node is laid out instead, cached by its node list.
- elkjs runs in its own worker, spawned from the session on the first layout and terminated with it (`elk.ts`: `elk-api` plus `elk-worker.min.js?url`). Tests swap in the bundled build's in-thread fake worker (`test-setup.ts`).
- "Visited" compares the colour array with its unvisited value: the sparse default, else `-1` when any cell holds it, else an INF-sized value (|v| ≥ 1e9), else `0`/`false`. The legend states the rule (`dist ≠ -1`), because it is a guess (§19.2 #4).
- In a parent array a sparse array's default cells have no parent, and a dense array that holds one value everywhere has no edges.
- sigma 4 draws the layout in WebGL, one instance per layout; each step only merges attributes into its graphology graph. elkjs keeps the positions; its edge routes are dropped, so an edge is straight unless the straight line crosses another node's box, then curved. The canvas is the layout's size at 1:1 inside a scrolling box, never shrunk to fit. Captions (`dist=1`), `◀ u` and edge weights are DOM spans on a sigma layer, placed after every render. sigma's own runtime lives only in `graph-canvas.ts`, loaded with `import()` on the first graph view; tests replace that module (`test-setup.ts`).
- The first-visit (DFS) tree, computed in the worker over the whole trace (`firstVisits`): a node is visited at a step where its colour cell goes from the unvisited value to another, and that unvisited value is what every cell last held at once (`fill(dist, ..., -1)` gives `-1`, a zeroed `vis[]` `false`). Its parent is the first index variable of the adjacency list (`u` in `adj[u]` or `for (v : adj[u])`), looked up from the innermost frame outward, that holds another node with an edge to it. An edge holds from that step until the node turns unvisited again.

**Why:** a per-step layout jumps every time an edge arrives, which §19.10 rules out. The bundled elkjs, loaded in a Web Worker, finds no fake worker to export and sets `self.onmessage`, which would take the Comlink messages meant for the engine; it failed with "_Worker is not a constructor". A zeroed `dist[]` before `fill(-1)` would otherwise make every node visited at the first step. Looking outward through the frames gives one rule for BFS (`dist[v] = dist[u] + 1`, `u` in the same frame) and recursive DFS (`vis[u] = true`, the parent's `u` in the caller's frame). A zeroed global `int par[N]` otherwise reads as every node under node 0 at the first step, and the union then keeps that phantom tree in the layout. sigma (the owner's pick, spec v1.18) gives pan and zoom and draws 200 nodes without DOM nodes per edge. Shrinking a big graph to fit the card scales the boxes too, while sigma's labels stay 12px and overflow them. sigma rotates edge labels along the edge, so `9` reads sideways, and it draws a label attachment only for a node with a backdrop, centring label and attachment together, so a caption overlaps its box: hence the DOM layer. Its display default `labelFont: "sans-serif"` wins over the primitives' font, so the style sets `labelFont`. `sigma/rendering` reads `WebGL2RenderingContext` on import, which jsdom lacks.

**How to apply:** keep layouts keyed by object, kind and the undirected choice; don't lay out per step. Don't import `elkjs/lib/elk.bundled.js` outside tests. Don't import sigma's runtime outside `graph-canvas.ts`, and don't let sigma rescale a graph below 1:1 at fit. A new graph source adds its shape to `graphShape` so the union and the view read it the same way.
